# 配置说明（给画师、建模师和想细调的人）

## 原理

不是 Live2D，也没有网格编辑器。每个部件是一张平面图，按「它在头上的深度 + 头是个球面」算出位移场，
再用 cv2.remap 逐层扭一下。转头时：刘海（深度大）挪得多，后发（深度负）往反方向挪，脸中间鼓、边缘不动，
下巴附近被钉住不离开脖子。所有数字都在 `config.json` 里，坐标一律是 PSD 画布像素。

一个模型文件夹：
```
models/<名字>/
  config.json   怎么动
  parts.json    每张图在画布上的位置 {canvas, parts:[{id,x,y,w,h}]}
  parts/*.png   裁好边的部件图，文件名 = id
```
config.json 里没写的字段用 `psd2pet/config.py` 里的默认值；写了但 parts.json 里没有的部件会被跳过，不会崩。

## 导入器怎么认图层

`python -m psd2pet.import_psd <psd 或文件夹> --out models/<名字> [--name 显示名] [--force] [--no-preview]`

- PSD：从下往上走。文件夹里还有文件夹就继续往里拆；最里面那层文件夹（或单独的图层）= 一个部件，
  里面的线稿/上色/正片叠底先合成一张。隐藏的部件会在内存里临时打开再合成，PSD 文件不会被写。
- PNG 文件夹：文件名排序 = 从下往上，每张必须是完整画布大小。
- 动作组：先看最外层文件夹名，认不出再从部件名往外一段段找。关键字表在 `import_psd.py` 顶部的
  `GROUPS`、`ROLES`、`DESK_PARTS`，可以直接加自己的词。
- 隐藏的普通部件当草稿丢掉；隐藏的表情和桌面部件保留。
- 嘴：名字带「平常/默认/normal」的是平时的嘴；没有就用看得见的那张；其余都是说话时换着用的。
- 第二张「闭眼」会当作笑眼。
- 自动算出来的：画布范围、默认大小（窗口约 430 像素高）、脸的椭圆
  （有「脸」图层按脸算）、眼睛中心、嘴的位置、脖子钉点、手的握点。挪动幅度按脸宽等比缩放。

## 字段对照

### 窗口和大小
| 字段 | 意思 |
|---|---|
| `name` / `slug` | 显示名 / 设置文件夹名（`%APPDATA%\PSD2Pet\<slug>`） |
| `mode` | `sitting` 坐在桌前（桌垫、鼠标、手）/ `standing` 站着 |
| `canvas` | [x, y, w, h] 窗口显示画布的哪一块 |
| `scale` | 大小 {default 第一次打开的缩放, min 最小, max 最大, step 滚一格放大几倍}。之后用户自己滚轮调，菜单里能恢复默认 |
| `icon_box` | 托盘图标截哪块 [左, 上, 边长] |
| `sleep_after` | 多少秒不碰键鼠就睡 |

### 头
| 字段 | 意思 |
|---|---|
| `look.neck` | 视线计算的原点（脖子） |
| `look.yaw` / `pitch` | 左右 / 上下最多转多少 |
| `look.tanh_x` / `tanh_y` | 鼠标离多远就转到头（像素） |
| `fields.head` | 脸的椭圆 [cx, cy, rx, ry]，鼓起的范围 |
| `head.shift` / `up` / `down` | 整个头跟着转时平移多少 |
| `head.bang_up` / `bang_down` | 刘海额外挪多少 |
| `head.pin` | [钉住的 y, 过渡高度, 横向保留, 纵向保留]。y 放在下巴，脖子裂开就把保留调小 |
| `head.lag_max` / `roll_lag` | 头发跟随慢半拍的程度 |

### 每个部件 `layers[]`（顺序 = 从下往上画）
| 字段 | 意思 |
|---|---|
| `id` | 对应 parts/<id>.png |
| `group` | head 头 / bang 刘海 / back 后发 / loose 挂件 / body 身体 |
| `z` | [x, y] 深度。正数往转头方向挪，负数往反方向 |
| `bulge` | [x, y] 球面鼓起量。脸大一些，刘海小一些，后发 0 |
| `field` | 这层用的椭圆，一般就是 fields.head 或 fields.body |
| `hang` | 垂挂（长发、飘带）：{root 根部 y, amp 幅度, spring "rib"/"hair"} |
| `bend` | 发梢慢半拍：{root, amp, spring} |
| `tassel` | 吊坠、穗子：{root, amp} |
| `anchor` | `"eyes"` 跟着眼睛走 / [x, y] 整块跟着这个点走（不被球面扭） |
| `clip` | 只在这些层里面显示（眼珠被眼白裁掉就是这个） |
| `blend` | `multiply` 正片叠底 |

`spring`：`rib` 更软更慢，`hair` 稍快。

### 五官 `faces`
`white` 眼白、`iris` 眼珠、`line` 眼线、`brow` 眉毛、`closed` 闭眼、`happy_eye` 笑眼、
`blink` / `sleep` 眨眼和睡觉用哪张、`mouth` 平时的嘴、`mouths` 说话时轮换的嘴。值是部件 id，没有就写 null。

| 字段 | 意思 |
|---|---|
| `eyes.centers` | 两只眼睛的中心，眨眼往这里压 |
| `eyes.mid_x` | 左右眼分界 |
| `eyes.brow_y` | 眉毛高度 |
| `eyes.pupil` | 眼珠最多挪多少 [x, y] |
| `eyes.foreshorten` | 转头时远侧眼收窄、近侧眼放宽多少 |
| `mouth.center` / `top` | 张嘴的中心、上沿 |
| `blink` | 眨眼的两段时长（秒） |

### 坐着模式 `desk`
| 字段 | 意思 |
|---|---|
| `parts` | 不变形、直接贴的部件：mousepad、doll、mouse、hand_l、hand_r_up、hand_r_down |
| `shoulder_l` / `shoulder_r` | 肩膀，手臂从这里转 |
| `grip_l` | 左手握鼠标的点 |
| `tip_r` | 右手指尖按键的点 |
| `mouse` | 桌上鼠标跟着真鼠标挪的范围 [左右, 往上, 往下]（像素），0 = 不挪 |
| `doll_center` | 小玩偶缩放的支点（相对位置 0~1） |

### 其它
| 字段 | 意思 |
|---|---|
| `keys` | 按键显示 {show 默认开不开, pos 位置, max_w 最宽} |
| `zzz` | 睡觉的 Zzz {at 起点, drift 飘多远, color} |
| `voice` | 声捕 {open 张嘴阈值, gates 灵敏度档位} |
| `window.key_color` | 直播窗口底色（OBS 色度键抠掉） |
| `shadow` | 站立模式脚下的影子 {on, size, color, at} |

## 调参流程

1. 改一个字段。
2. `python -m psd2pet --model models/<名字> --preview out.png`
3. 对比前后两张图。`out_turn.png` 是转头扫描，专门看撕裂。

## 进阶

- 耳朵抖动、呆毛弹动是专门写的小动作：部件 id 必须叫 `ears` / `ahoge`，并在 layer 里写 `ear` / `ahoge` 参数，
  参数比较多，看 `psd2pet/rig.py` 里的 `local()` 和 `_ear_local()`。
- 想加新的动作组、新的表情触发，改 `rig.py`。引擎是配置驱动的，加字段时记得在 `config.py` 的 DEFAULTS 里给默认值。
