# 桌宠拆层需求单（可以直接发给画师）

你好！我想用 PSD2Pet 把这张 Q 版立绘做成会动的桌宠（会转头、眨眼、看鼠标、说话张嘴、打字）。
麻烦拆层时按下面几条来，谢谢～

## 一、总规则

1. 一个会动的部件 = 一个文件夹。文件夹里面线稿、上色、阴影、高光随便分，程序会先合成一张。
2. 文件夹名里带上下面表格里的关键字就行，前后加什么都可以（例如「刘海-左」「前发2」都认）。
3. 不要合并图层，不要栅格化成一张，不要裁画布。
4. 备用表情（闭眼、张嘴等）直接留在 PSD 里，隐藏着就行，不用删。
5. 被头发、手挡住的地方请多画一点（脸的边缘、刘海后面的额头、耳朵根），转头时会露出来。

## 二、头部（转头时一起动）

| 部件 | 文件夹名关键字 | 说明 |
|---|---|---|
| 脸 | 脸 | 只要脸皮，不带五官 |
| 眼白 | 眼白 | 左右眼可以放一起 |
| 眼珠 | 眼珠 / 瞳孔 | 要比眼白露出来的部分大一圈，眼珠会转动，边缘被眼白裁掉 |
| 眼线 | 眼线 | 上下睫毛、眼眶。眉毛可以一起放这里，也可以单独一个「眉毛」 |
| 闭眼 | 闭眼 | 眨眼、睡觉用。一条线就行 |
| 笑眼（可选） | 笑眼 / 眯眼 | 被点的时候用 |
| 平时的嘴 | 嘴-平常 | 名字里一定要有「平常」 |
| 张嘴 | 嘴-张 | 说话用 |
| 小张嘴（可选） | 嘴-小 | 说话用，越多张越自然 |
| 耳朵 / 头饰 / 鬓发 | 耳 / 鬓 / 侧发 / 头 | 跟着头转 |

## 三、头发

| 部件 | 关键字 | 说明 |
|---|---|---|
| 前面的刘海 | 刘海 / 前发 | 盖在脸上的那片，转头时动得比脸多 |
| 后面的头发 | 后发 / 马尾 / 丸子 / 呆毛 | 在脸后面的，转头时往反方向动一点 |
| 挂件、飘带 | 挂件 / 飘带 / 蝴蝶结 / 坠 | 会晃 |

## 四、身体

| 部件 | 关键字 | 说明 |
|---|---|---|
| 身体、衣服 | 身体 / 衣服 | 可以是一整块 |

全身站立的桌宠到这里就够了。

## 六、交付

- 首选：PSD 源文件（只给拆层版也可以）。
- 不方便给 PSD 的话：每个部件导出一张 PNG，**每张都保持完整画布大小**（不要裁边，位置才对得上），
  文件名用上面的关键字，前面加两位数字表示从下往上的顺序，例如：
  `01 身体.png`、`02 后发.png`、`03 脸.png` …… `20 刘海.png`。

不确定的地方随时问我，谢谢！
