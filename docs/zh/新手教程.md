# 新手教程：第一次做桌宠

不会写代码也没关系。整个流程就是：拿到拆好的图 → 导入 → 看预览图 → 不满意就改几个数字 → 打包成 exe。

## 你需要准备

1. 一台 Windows 电脑。
2. 角色图：拆好层的 PSD，或者每个部件一张、保持完整画布大小的 PNG。
   还没拆的话，把《拆层需求单》发给画师。
3. Python 3.10 或更新版本（https://www.python.org ，安装时勾上「Add Python to PATH」）。

图的版权归画师和你。打包好的 exe 里有你的图，发给别人之前先和画师确认。

## 两种做法

### 做法 A：让 AI 帮你（推荐萌新）

如果你在用 Claude Code、Cursor 这类能操作电脑的 AI 助手：

1. 把这个项目下载到电脑上，用 AI 助手打开这个文件夹。
2. 把 `skill/psd2pet` 装成它的 skill（Claude Code：复制到 `.claude/skills/psd2pet`）。
3. 跟它说：「帮我把 D:\我的角色.psd 做成桌宠」。

它会按 skill 里的步骤导入、出预览图给你看、按你说的改。你只需要看图、说哪里不对，比如「头转得太猛了」「眼睛跑出眼眶了」。

### 做法 B：自己动手

在项目文件夹里，地址栏输入 `cmd` 回车，打开黑框框，依次输入：

1. 装环境（只做一次）
   ```
   python -m venv .venv
   .venv\Scripts\python -m pip install -r requirements.txt
   ```
2. 导入（把路径和名字换成你的）
   ```
   .venv\Scripts\python -m psd2pet.import_psd "D:\我的角色.psd" --out models\xiaohu --name 小狐
   ```
   PNG 文件夹也一样，把 psd 路径换成文件夹路径。
3. 打开 `models\xiaohu\preview.png` 看效果。一张图里有待机、往各个方向看、眨眼、被点、睡觉、打字、说话。
   `preview_turn.png` 是转头扫一遍，看有没有裂开。
4. 满意了就开起来试试
   ```
   .venv\Scripts\python run_pet.py --model models\xiaohu
   ```
   右键或者托盘图标有菜单，在桌宠身上滚滚轮调大小。菜单跟着系统语言走，「语言 Language」里能换中文/英文。
5. 打包成 exe
   ```
   .venv\Scripts\python build_exe.py --model models\xiaohu
   ```
   做好在 `dist\小狐\小狐.exe`，整个文件夹一起拷走就能用。

## 导入时它跟你说了什么

- `[没放进去] xxx`：这个部件名字里没有认得的关键字，所以没用上。改一下名字再导入，或者看《配置说明》手动加。
- `五官：{...}`：认到了哪些眼睛、嘴。没有闭眼就不会眨眼，只有一张嘴就不会说话张嘴，其它照常。
- `桌子：[...]`：认到了哪些桌面部件。一个都没有就是站立模式。

## 常见问题

预览里头转得太猛 / 刘海和脸错开 / 脖子裂开 / 眼珠跑出去？
打开 `models\xiaohu\config.json`，照《配置说明》里的对照表改对应的数字，改完重新出预览：
```
.venv\Scripts\python -m psd2pet --model models\xiaohu --preview models\xiaohu\preview.png
```
一次只改一个地方，对比前后两张图，最好改。

站立模式也想显示按键？
右键菜单里打开「显示按键」就行。

玩游戏时它不跟着按键动？
有些游戏是管理员权限运行的，菜单里打开「管理员模式」。
