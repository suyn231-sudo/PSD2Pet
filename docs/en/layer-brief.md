# Layer brief for artists (send this as-is)

Hi! I'd like to turn this chibi illustration into a desktop pet with PSD2Pet (it turns its head, blinks,
follows the mouse, opens its mouth when I talk, and types along). Please split the layers like this. Thank you!

## 1. General rules

1. One moving part = one folder. Inside it, lineart / colour / shading can be any number of layers; they get merged.
2. Put one of the keywords below somewhere in the folder name ("bangs-left", "bangs 2" are fine).
   Chinese keywords work too (see the Chinese brief).
3. Don't merge or flatten, don't crop the canvas.
4. Keep alternate expressions (closed eyes, open mouth…) in the PSD, hidden. No need to delete them.
5. Paint a little extra under things that cover each other (face edge, forehead under the bangs, ear roots):
   it shows when the head turns.

## 2. Head (moves together when turning)

| Part | Keyword | Notes |
|---|---|---|
| Face | face | skin only, no features |
| Eye whites | white / sclera | both eyes in one folder is fine |
| Irises | iris / pupil | a bit larger than the visible area; they move and get clipped by the whites |
| Eye lines | eyeline | lashes and outline. Brows can go here or in their own "brow" folder |
| Closed eyes | closed / blink | for blinking and sleeping |
| Happy eyes (optional) | happy / smile | shown when poked |
| Normal mouth | mouth-normal | must contain "normal" |
| Open mouth | mouth-open | for talking |
| More mouths (optional) | mouth-small | more shapes = more natural talking |
| Ears / accessories / side hair | ear / head | follow the head |

## 3. Hair

| Part | Keyword | Notes |
|---|---|---|
| Front bangs | bangs / fringe | moves more than the face |
| Back hair | hairback / tail / bun / ahoge | moves a little the other way |
| Charms, ribbons | charm / ribbon / loose | swing |

## 4. Body

| Part | Keyword |
|---|---|
| Body, clothes | body / clothes |

That's all a standing pet needs.

## 5. Sitting at a desk (optional, only for the keyboard + mouse version)

| Part | Keyword | Notes |
|---|---|---|
| Desk mat (keyboard drawn on it) | mousepad / mat | |
| Mouse | mouse | |
| Left hand | lefthand | holding the mouse |
| Right hand, pressing | rightdown | on the keyboard |
| Right hand, lifted | rightup | alternates with the one above while typing |
| Little plush (optional) | doll / plush | |

## 6. Delivery

- Preferred: the PSD (a split-layer copy is enough).
- If you can't share the PSD: export one PNG per part, **each at full canvas size** (not cropped, so positions
  line up). Name them with the keywords, prefixed by a two-digit bottom-to-top order:
  `01 body.png`, `02 hairback.png`, `03 face.png` … `20 bangs.png`.

Feel free to ask me anything. Thanks!
